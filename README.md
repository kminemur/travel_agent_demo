## 基本プロンプト

```text
あなたは旅行プランナーです。東京から北海道へ行く二泊三日の旅行計画を作成してください。

【旅行条件】

- 旅行者：大人2人
- 旅行時期：次に訪れる1月（年が曖昧な場合は、現在日から見て次の1月として明記する）
- 総予算：2人合計20万円以内
- 食事：新鮮な海鮮を十分に楽しみたい
- レンタカー：使用しない
- 移動：移動時間と乗り換えをできるだけ少なくする
- 混雑：有名観光地のピーク時間や行列をできるだけ避ける
- 出発地・帰着地：東京（羽田空港の利用を優先して検討する）

【計画方針】

1. 条件に最も合う北海道内の目的地を選び、最初に選定理由を説明する。
2. 複数都市を無理に周遊せず、同じホテルへの連泊を優先する。
3. レンタカーなしで、空港バス、鉄道、路面電車、徒歩などで完結させる。
4. 平日、開館直後、早めの食事、日没前などを活用して混雑を避ける。
5. 海鮮は観光客向けの有名市場だけでなく、比較的混雑しにくい市場や予約可能な店も候補にする。
6. 1月の積雪、低温、交通遅延を考慮し、各日に十分な余白を設ける。
7. 悪天候や運休時の代替案も記載する。

【調査要件】

- 航空券、ホテル、公共交通、観光施設の料金・営業時間・所要時間は、作成時点の最新情報をウェブで確認する。
- 交通機関、自治体、観光施設、航空会社などの公式情報を優先する。
- 航空券とホテルは、モデル日程に対する現実的な検索価格を参考にする。
- 料金が変動するものは概算であることを明記し、予約時・出発前の再確認を促す。
- 参照したウェブページを資料末尾に一覧化する。

【必須の内容】

1. 旅の概要
   - 推奨目的地
   - モデル日程
   - 目的地を選んだ理由
   - この計画が各旅行条件をどう満たすか

2. 予算表
   - 往復交通費
   - 宿泊費（2泊・1室）
   - 食費
   - 現地交通費
   - 観光施設料金
   - 雑費・予備費
   - 合計額
   - 20万円からの残額

3. 一日ごとのスケジュール
   - 各日について時刻順の表を作る。
   - 各行に、時刻、行動・場所、移動手段と所要時間、食事内容、そのプランを選んだ理由、混雑を避ける工夫を含める。
   - 初日は東京出発から、最終日は東京帰着まで記載する。

4. 実用情報
   - 航空便を選ぶ際の推奨時間帯
   - 推奨するホテルの立地条件
   - 公共交通の乗車券・ICカードの使い分け
   - 1月の服装と雪道対策
   - 予約するべき食事や施設
   - 悪天候・運休・フライト遅延時の差し替え案

【PDFの仕様】

- 最終成果物は日本語のPDFにまとめる。
- A4縦、読みやすい和文フォントを使用する。
- 表紙、旅の概要、予算、各日の計画、チェックリスト、情報源を含める。
- 時刻表と予算表は表形式にし、見出し・配色・余白を統一する。
- ページ番号、作成日、「料金・時刻は予約時に再確認」の注記を入れる。
- PDF生成後に全ページを画像としてレンダリングし、文字化け、欠け、重なり、表のはみ出し、改ページの不具合がないことを確認してから提出する。

条件に合わない観光地を数多く詰め込むのではなく、「海鮮を楽しめること」「移動が短いこと」「混雑を避けられること」を優先して、実行しやすい旅行計画にしてください。
```

## 追加プロンプト1

```text
旅行計画の中から、条件に合うホテル候補を3件、海鮮を楽しめる飲食店候補を5件に絞ってください。
それぞれについて、価格の目安、アクセス、選定理由、予約の要否、公式情報へのリンクを表にし、旅行計画とPDFへ反映してください。
```

## 追加プロンプト2

```text
この旅行を実際に予約・実行するためのチェックリストを作成してください。
「今すぐ予約するもの」「出発1週間前に確認するもの」「前日・当日に確認するもの」に分け、悪天候や交通機関の運休時に切り替える代替案も含めてPDFへ反映してください。
```
